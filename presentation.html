Structured Output

Tool Calling 흐름

LLM이 직접 함수를 "호출"하는 것이 아니라, 호출 의도를 JSON으로 표현

중요: LLM은 함수를 실행하지 않습니다. "이 함수를 이 인자로 호출해달라"는 요청을 생성할 뿐입니다. 실행은 우리 코드의 몫입니다!
Structured Output

tool_choice 옵션

옵션동작사용 시기
"auto" LLM이 알아서 판단
Tool 호출 or 텍스트 응답		 일반적인 대화형 Agent
"required" 반드시 하나 이상의 Tool 호출
텍스트만 응답 불가		 무조건 액션이 필요한 경우
"none" Tool 호출 금지
텍스트 응답만 가능		 최종 답변 생성 단계
{"type":"function",

안전장치: 허용 명령어 & 경로 제한

 1# 화이트리스트 기반 명령어 필터
 2ALLOWED_COMMANDS = {"ls", "cat", "grep", "find", "head",
 3                    "wc", "python", "pip", "git"}
 4BLOCKED_PATTERNS = ["rm -rf", "sudo", ":(){:|:&}", "dd if="]
 5ALLOWED_DIR = "/home/user/workspace"
 6
 7def validate_command(cmd: str) -> bool:
 8    # 1. 위험 패턴 차단
 9    for pattern in BLOCKED_PATTERNS:
10        if pattern in cmd:
11            return False
12
13    # 2. 첫 번째 명령어가 허용 목록에 있는지
14    base_cmd = cmd.split()[0].split("/")[-1]
15    if base_cmd not in ALLOWED_COMMANDS:
16        return False
17
18    # 3. 경로 이탈 방지
19    if ".." in cmd or cmd.startswith("/"):
20        return False
21    return Truepython
