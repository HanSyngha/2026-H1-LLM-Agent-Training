# 강의 피드백 / Training Feedback

> 본 강의(2-Day LLM Agent Workshop)는 2026년 상반기 사내 교육 과정으로 **총 3차수, 160명**의 수강생을 대상으로 진행되었습니다.
> 이 폴더는 각 차수에서 수집된 익명 설문 피드백을 기록합니다.

This workshop was delivered as an internal training program in 2026 H1.
**3 cohorts · 160 participants** (mostly non-SW engineering roles, with some SW engineers mixed in).

## 🎯 가장 많이 언급된 키워드

### 좋았던 점 (Top Themes)
1. **열정적인 강의 / 강사 전문성** — 30+ 멘션
2. **실습 중심 / 직접 해보는 경험** — 25+ 멘션
3. **사내 환경(SSO, LLM Gateway, opencode)에서 바로 적용 가능** — 20+ 멘션
4. **강의 자료 퀄리티 / 알찬 교안** — 15+ 멘션
5. **AI 전반의 흐름·트렌드·원리 설명** — 12+ 멘션

### 개선 요청 사항
1. **속도 조절** — 입문자에겐 진행이 빠르게 느껴짐 (특히 3차수 비SW 80인)
2. **기초 개념 보강** — RAG, LLM 등 용어/배경 설명 추가 요청
3. **교육 기간 연장** — "2일 너무 짧음, 5일 받고 싶음" 등
4. **사내 서버 속도** — opencode 동시 사용 시 응답 지연
5. **사후 학습 자료** — 슬라이드/실습 자료 복습 가능 환경
