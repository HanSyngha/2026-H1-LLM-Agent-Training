# 실습: CLI Agent 만들기

## 목표
파일 시스템을 탐색하고 조작하는 Agent를 직접 구현합니다.

---

## 요구사항

### 필수

1. **최소 3개의 CLI 도구 구현**
   - 각 도구는 독립적인 Python 함수
   - 문자열 반환 (LLM이 이해할 수 있는 형태)
   - OpenAI Tool Schema 정의 포함
   - 적절한 에러 처리

2. **안전장치 추가**
   - 허용 명령어 목록 (allowlist) 또는 차단 명령어 목록 (blocklist)
   - 경로 제한 (특정 디렉토리 하위만 접근 가능)
   - 명령어 실행 타임아웃
   - 출력 크기 제한

3. **Agent Loop 통합**
   - Session 1에서 구현한 Agent Loop 활용
   - 도구 등록 및 디스패치
   - 대화형 인터페이스

### 보너스

4. **실행 확인 기능**
   - 위험한 작업 (파일 삭제, 명령어 실행) 전에 사용자 확인
   - "이 명령어를 실행할까요? (y/n)" 형태

5. **실행 로그**
   - 모든 도구 실행을 로그 파일에 기록
   - 타임스탬프, 도구 이름, 인자, 결과 포함

---

## 구현할 도구 예시

아래에서 최소 3개를 선택하여 구현하세요:

| 도구 | 설명 | 난이도 |
|------|------|--------|
| `list_directory` | 디렉토리 목록 조회 | 쉬움 |
| `read_file` | 파일 내용 읽기 | 쉬움 |
| `write_file` | 파일 생성/수정 | 보통 |
| `run_command` | 시스템 명령어 실행 | 보통 |
| `search_files` | 파일 검색 (glob) | 보통 |
| `run_powershell` | PowerShell 실행 | 보통 |
| `get_file_info` | 파일 상세 정보 (크기, 수정일 등) | 쉬움 |
| `create_directory` | 디렉토리 생성 | 쉬움 |
| `move_file` | 파일 이동/이름 변경 | 보통 |
| `grep_content` | 파일 내용 검색 (텍스트) | 보통 |

## 테스트 시나리오

구현 후 다음 시나리오로 테스트하세요:

1. **기본 탐색**
   ```
   사용자: 현재 디렉토리에 어떤 파일이 있어?
   Agent: (list_directory 호출) → 파일 목록 표시
   ```

2. **파일 읽기**
   ```
   사용자: cli_tools.py 파일 내용을 보여줘
   Agent: (read_file 호출) → 파일 내용 표시
   ```

3. **복합 작업**
   ```
   사용자: Python 파일을 모두 찾아서 각 파일의 첫 3줄을 보여줘
   Agent: (search_files → read_file x N) → 정리된 결과
   ```

4. **안전장치 확인**
   ```
   사용자: /etc/passwd 파일을 읽어줘
   Agent: 접근 거부 메시지 (경로 제한 동작 확인)
   ```

## 주의사항

- `subprocess.run()`에서 `shell=True`는 편리하지만 보안 위험이 있습니다.
- 사용자 입력을 직접 명령어에 넣지 마세요 (Command Injection).
- 파일 경로는 항상 정규화(`os.path.abspath`) 후 검증하세요.
- 타임아웃을 반드시 설정하세요 (무한 실행 방지).
