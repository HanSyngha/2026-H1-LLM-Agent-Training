# NovaChat v2.0 릴리즈 노트

릴리즈 일자: 2025년 2월 28일
작성자: 최유진, 조민기

## 🎉 주요 변경사항

### 1. Context Length 확장
- v1: 8k tokens → **v2: 32k tokens**
- 긴 문서도 한 번에 처리 가능

### 2. 다국어 지원
- v1: 한국어 전용
- **v2: 한국어 + 영어 혼합** 지원
- 한/영 섞인 문서도 자연스럽게 처리

### 3. 과금 모델 추가
- 기존: 월 구독만 (50,000원/사용자)
- **추가: 종량제 옵션** (API 호출당 과금)
- 월 구독 가격도 **50,000원 → 49,000원**으로 인하
- (2025-02-10 제품기획 회의에서 최종 결정)

### 4. 응답 지연 개선
- v1 평균 1.2초 → v2 평균 0.7초

### 5. 도구 사용(Tool Use) 지원
- 외부 API 호출, SQL 실행, 파일 읽기 등

## 마이그레이션 가이드
- v1 사용자는 자동으로 v2로 업그레이드됨
- 단, Context 길이 이점을 활용하려면 프롬프트 재설계 필요

## 알려진 이슈
- 긴 Context(> 20k) 사용 시 약간의 지연 발생
- 일부 고객사의 커스텀 플러그인과 호환성 문제 (해결 예정: 2025-03 말)
