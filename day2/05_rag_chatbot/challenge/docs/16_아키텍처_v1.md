# 뉴럴웍스 시스템 아키텍처 v1

작성: 윤채원 (인프라팀장)
최종 업데이트: 2024-10-15
상태: **Deprecated (v2로 마이그레이션 중)**

## 개요
뉴럴웍스 초기 아키텍처는 AWS EKS를 중심으로 한 단일 클라우드 구성이었습니다.

## 구성 요소

### 컴퓨트
- AWS EKS (단일 클러스터, ap-northeast-2)
- 노드 타입: p3.8xlarge (V100) × 8
- 자동 스케일링: HPA + Cluster Autoscaler

### 데이터 저장소
- **메인 DB**: PostgreSQL 14 (RDS Multi-AZ)
  - 트랜잭션 + 분석 쿼리 모두 처리
- **세션 캐시**: Redis (ElastiCache)
- **오브젝트 저장**: S3
- **벡터 인덱스**: Faiss (파일 기반)

### 모델 서빙
- vLLM on k8s
- 모델 저장: S3 → init container로 로드

### 관찰성
- 로그: CloudWatch
- 메트릭: Prometheus + Grafana
- 트레이싱: AWS X-Ray

## 한계
