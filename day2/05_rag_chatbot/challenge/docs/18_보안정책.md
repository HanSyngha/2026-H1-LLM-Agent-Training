# 뉴럴웍스 정보보안 정책

담당: 보안팀 / CTO 승인
버전: 1.3
최종 수정: 2025-02-01

## 일반 원칙
- 최소 권한 원칙 (Principle of Least Privilege)
- 모든 접근은 로깅
- 민감 데이터는 암호화 (저장/전송 모두)

## 계정 및 접근 제어
- 모든 계정은 SSO(Okta) 연동
- 2FA 필수 (예외: 프린터)
- 퇴사자 계정은 퇴사 당일 비활성화
- 프로덕션 접근은 승인 기반 (JIT)

## 데이터 분류
| 등급 | 설명 | 예시 |
|-----|-----|-----|
| 기밀 | 유출 시 심각 피해 | 고객 개인정보, 모델 가중치 |
| 내부 | 사외 공유 금지 | 내부 문서, 회의록 |
| 공개 | 자유 배포 가능 | 블로그, 마케팅 자료 |

## 코드 보안
- 모든 PR은 최소 1명 리뷰 필수
- Secret 검출 훅 (pre-commit)
- 의존성 취약점 자동 스캔 (Dependabot)
- 월 1회 SAST 실행
