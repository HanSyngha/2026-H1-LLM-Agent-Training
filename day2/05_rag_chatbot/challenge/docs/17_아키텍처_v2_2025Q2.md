# 뉴럴웍스 시스템 아키텍처 v2

작성: 윤채원 (인프라팀장) / 강태민 (엔지니어링본부장) 검토
버전: 2.0
발효: 2025년 Q2 (6월 완료 목표)
상태: 🚧 마이그레이션 진행 중

## 주요 변경사항

### 1. 하이브리드 인프라 (vs v1 단일 클러스터)
- **v1**: AWS EKS 단일 클러스터
- **v2**: AWS EKS + 온프렘 k8s 하이브리드
- 온프렘 H100 4대 (2025-03-05 경영진 회의에서 승인)
- 데이터 주권 요구 고객 대응 가능
- 평시 80% 온프렘 사용, 피크 시 AWS로 스필오버

### 2. 데이터 저장소 분리 (vs v1 PostgreSQL 단일)
- **v1**: PostgreSQL이 트랜잭션 + 분석 모두 처리
- **v2**:
  - 트랜잭션: PostgreSQL 15 유지
  - **분석/로그 쿼리: ClickHouse 신규 도입** ⭐
  - 성능 테스트 결과: 분석 쿼리 평균 15배 빨라짐

### 3. 벡터 DB
- v1: Faiss 파일 기반
- v2: Qdrant 클러스터 (분산)

### 4. 모델 서빙
- 기존 vLLM 유지
- 라우터 추가: 한국어/영어 모델 분리 라우팅

## 마이그레이션 일정
- Q2 1개월차 (4월): 온프렘 구축 완료
- Q2 2개월차 (5월): ClickHouse 도입 및 대시보드 전환
- Q2 3개월차 (6월): 전면 전환, v1 폐기
