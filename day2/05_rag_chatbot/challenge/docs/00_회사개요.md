# 뉴럴웍스(NeuralWorks) 회사 개요

뉴럴웍스는 2021년 설립된 한국의 AI 스타트업으로, 기업용 LLM 솔루션을 개발합니다.
본사는 서울 강남에 위치하며, 2024년 시리즈 B 라운드에서 200억 원을 투자받았습니다.

## 미션
"모든 기업이 자사 도메인에 특화된 AI를 소유할 수 있도록 한다."

## 핵심 가치
- 고객 중심
- 기술 투명성
- 빠른 실행

## 주요 제품군
- NovaChat (대화형 AI)
- NovaVision (이미지 이해 AI)
- NovaSearch (사내 검색)
