# 신입사원 온보딩 가이드

작성: HR팀 김나현
최종 업데이트: 2025-01-20

뉴럴웍스에 오신 것을 환영합니다! 아래는 4주 온보딩 일정입니다.

## 1주차 (Orientation)
- [ ] 입사 서류 제출
- [ ] 회사 소개 오리엔테이션 참석
- [ ] 노트북 세팅 (IT팀 지원)
- [ ] 사내 계정 생성 (Slack, Notion, GitHub, Jira)
- [ ] 멘토 배정 및 첫 인사

## 2주차 (필수 과제) ⭐
2주차에는 **반드시 다음 3가지**를 완료해야 합니다:

1. **보안 교육 이수** (온라인 모듈 4시간)
   - 정보보안, 개인정보보호, 코드 관리 원칙
2. **멘토와 1:1 미팅** (최소 1회, 권장 주 1회)
   - 업무 적응 피드백, 질문/고민 공유
3. **첫 PR(Pull Request) 올리기**
   - 사소한 문서 수정도 OK
   - 깃 워크플로우 체험 목적

## 3주차 (팀 업무 시작)
- 팀 스탠드업 참여
- 온보딩 태스크 수행
- 코드베이스 투어

## 4주차 (Wrap-up)
- 멘토와 온보딩 회고
- HR 면담
- 정식 업무 투입
