# NovaChat 제품 소개서 (v1.0)

NovaChat은 뉴럴웍스의 플래그십 제품으로, 기업용 대화형 AI 어시스턴트입니다.

## 주요 스펙
- 베이스 모델: 자체 파인튜닝 Transformer
- Context Length: **8k tokens**
- 지원 언어: **한국어 전용**
- 응답 지연: 평균 1.2초

## 가격
- Standard: 월 **50,000원** / 사용자
- Enterprise: 별도 견적
- 무료 체험: 14일

## 주요 기능
1. 사내 문서 기반 QA
2. 회의록 자동 요약
3. 이메일 초안 작성
4. 코드 리뷰 보조

## 대상 고객
- 직원 100~500명 규모의 중견 기업
- 한국어 문서 위주로 업무하는 팀
