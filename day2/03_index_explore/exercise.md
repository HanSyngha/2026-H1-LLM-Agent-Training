## 실습 3: 하이브리드 접근법 설계

### 과제

여러분의 실무 프로젝트에 적용할 하이브리드 검색 시스템을 설계하세요.

### 설계 요구사항

1. **질의 분류기 설계**
   - 입력 질의를 분석하여 코드/문서/혼합 중 어디에 해당하는지 판별
   - 판별 기준과 로직을 코드로 구현

2. **검색 파이프라인 설계**
   ```
   사용자 질의
     -> 질의 분류
     -> [코드] Index 검색 (glob -> grep -> AST)
     -> [문서] Semantic 검색 (임베딩 -> 벡터 DB)
     -> [혼합] 양쪽 모두 실행 후 결과 병합
     -> 결과 순위 재조정 (re-ranking)
     -> 최종 결과 반환
   ```

3. **결과 병합 전략**
   - 두 방식의 결과를 어떻게 합칠 것인지
   - 순위는 어떤 기준으로 매길 것인지
   - 중복 결과는 어떻게 처리할 것인지
